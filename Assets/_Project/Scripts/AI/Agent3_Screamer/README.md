# Agent 3 - The Screamer (Member 3: Core Developer + Screamer)

**Architecture:** Utility AI (response-curve considerations, Dave Mark-style compensation factor)
**Concept:** A support zombie that never fights. It scores *Wander / Scream / Flee / Hide* every 0.15 s from
what it has actually perceived, and when it screams it broadcasts the player's last known position to every other
zombie in earshot through an alert system.

## Try it
1. Open the project in Unity Hub (Unity 6000.6.2f1). First import takes a few minutes.
2. When scripts finish compiling, the project **auto-builds** materials, the Animator Controller, prefabs and
   `Assets/_Project/Scenes/Screamer_Demo.unity` (with a baked NavMesh). Watch the Console for `[Screamer] Done`.
   If it doesn't run: `Tools > Screamer > Rebuild Prefabs And Demo Scene`.
3. Press Play. WASD / Shift / mouse / F (flashlight) / H (hide HUD) / Esc (free cursor).
   Walk the S-shaped route north; the Screamer spots you, screams (red ring), 5 dummy zombies converge, it hides behind a locker.

## Utility AI (for the viva)
Inputs: `Threat` (1 = seeing the player now, decays to 0 over `memorySeconds`), perceived distance `d` (to the *last known*
position - no cheating), allies in earshot, nearest ally distance, scream cooldown, cover availability, hidden time.

| Action | Considerations (all 0..1, multiplied) |
|---|---|
| Wander | Calm = linear(1-Threat) x 0.30 weight |
| Scream | SeesPlayer (0/1) x CooldownReady (0/1) x Bell(d, 16m, +-16) x AlliesCanHear (0.4..1) |
| Flee | Proximity = power((14-d)/(14-4), 1.5) x Threat x AloneFactor (0.5..1) x StayHiddenUnlessCornered (0.35 if hidden & d>4m) |
| Hide | Threat x CoverAvailable x Bell(d, 10m, +-14) x ScreamedAlready (1 / 0.35) x Patience (fades over 18 s hidden) x 0.9 weight |

Final score = product with compensation factor (`v += (1-v)*(1-1/n)*v`) so actions with more considerations aren't unfairly low.
Stability: running action gets +20 % (`commitBonus`), `minActionSeconds`, and a scream can't be interrupted.
Typical flow: sees you at ~16 m -> **Scream** -> (cooldown) **Hide** at mid range -> **Flee** if you come within ~4 m -> back to **Wander** when it forgets you.
All numbers are public Inspector fields on `ScreamerBrain`; the HUD shows live scores and each consideration.

## Integration with teammates
* Member 1 (Director): `AlertSystem.AlertBroadcast` event fires on every scream; spawn extra zombies there if wanted.
  Bake the real NavMesh - `ScreamerBrain` uses the scene NavMesh. Put `HideSpot` on any prop.
* Member 2 (Tank / barricades) and Member 4 (Runner): add `ZombieAlertReceiver` (turn off `driveMovement` and use `onAlerted` /
  `LastAlertPosition`), or implement `IAlertListener` yourself. Colliders on barricades/doors also block the Screamer's sight and muffle screams.
* Player must be tagged `Player` (or assign `ScreamerBrain.player`).

## GV checklist (Member 3)
* Zombie: `Models/Characters/zombie_scream.fbx` - Humanoid rig (auto avatar), URP material `M_Screamer_Zombie` (diffuse + normal map;
  the specular map is not used by URP Lit).
* Prop: `Models/Props/wrecked_locker.obj` + `Textures/Props/wrecked_locker_albedo.png` -> `Prefabs/WreckedLocker.prefab` (collider + HideSpot).
  NOTE: this locker was generated by a script as a stand-in; replace it with your own Blender model if the rubric needs hand-modelled work
  (keep the prefab: swap the mesh, keep BoxCollider + HideSpot).
* Audio: `Audio/screamer_scream.wav` is a synthesized placeholder scream.
* The FBX contains only the scream animation; walking/running/crouching is procedural. Real Mixamo clips can replace it.

## Known limits
Written without Unity to test in. Tune `ZombieProceduralMotion` amplitudes if limbs look odd; if the model faces sideways,
rotate the `zombie_scream` child of the Screamer prefab on Y.
